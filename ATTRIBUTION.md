# Attribution

This plugin is original code, but its provider-adapter coverage, session-usage
folding, and heatmap presentation follow the approaches of these MIT-licensed
DSH plugins. Where a snippet is adapted, the source project is named in the
file header.

- lizhouai/dsh-provider-usage — MIT — provider balance/usage adapters, route
  discovery, credential seams: https://github.com/lizhouai/dsh-provider-usage
- Rannist/balance-dsh — MIT — session token folding, peak/off-peak model,
  heatmap layout, DeepSeek account balance precedence:
  https://github.com/Rannist/balance-dsh
- MeteorNOX/DeepSeek-Balance-Whale-Widget — MIT (code; bundled artwork is not
  MIT) — provider template list and per-provider field paths:
  https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget

DeepSeek pricing is read at runtime from the official price page
(https://api-docs.deepseek.com/zh-cn/quick_start/pricing/); no price table is
copied into this repository.
